قواعد التنفيذ
================================================================================

  1. مهمة واحدة صغيرة في كل مرة — لا تعليق طويل
  2. لا تغييرات خارج نطاق المرحلة الحالية
  3. كل commit يُدفع إلى master بعد اكتمال المهمة
  4. لا محتوى نسائي — تحقق من site-config.json و seed
  5. عند النشر على Render:
       Build:  npm run build  (أو Docker)
       Start:  cd apps/web && npm start
