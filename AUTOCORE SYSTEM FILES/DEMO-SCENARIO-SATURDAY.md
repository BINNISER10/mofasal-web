# سيناريو عرض مفصل — يوم السبت

> **الرابط الحي:** https://mofasal.netlify.app  
> **المدة:** 12–15 دقيقة  
> **الجمهور:** الشريك / المستثمر  
> **كلمة المرور لكل الأدوار:** `admin123`

---

## قبل العرض (دقيقتان)

1. افتح المتصفح في **نافذة خاصة** (Incognito) لتجنب جلسات قديمة.
2. تأكد من الاتصال بالإنترنت.
3. الرابط جاهز: **https://mofasal.netlify.app**
4. إذا تعطل API: اضغط أي زر تجريبي في صفحة الدخول — **وضع العرض يعمل بدون خادم**.

---

## المسار الكامل (12 دقيقة)

### 1️⃣ الصفحة الرئيسية — «انطباع أول» (2 دقيقة)

**الرابط:** `/`

**ماذا تقول:**
> «مفصل منصة سعودية للخياطة الرجالية — تجمع بين جاهز ولومار: طلب من البيت، قياس منزلي، وتتبع مراحل الخياطة خطوة بخطوة.»

**ماذا تُظهر:**
- Hero + فيديو/بانر
- إحصائيات (+2000 خياط، 50K طلب)
- أقسام: خدمات، حرفية، لوك بوك، خطوات العمل
- CTA «ابدأ الآن»

**نقطة قوة:** هوية سعودية (سدو، ألوان العلامة `#00373E` + ذهبي)

---

### 2️⃣ سوق المحلات — «اختر خياطك» (2 دقيقة)

**الرابط:** `/shops`

**ماذا تقول:**
> «العميل يتصفح محلات الخياطة حسب المدينة والتقييم — مثل جاهز لكن للتفصيل.»

**ماذا تفعل:**
1. اختر مدينة «الرياض»
2. افتح محل «خياطة الرجال الراقية»
3. أظهر الخدمات (ثوب، بدلة، تعديل) والأسعار

**نقطة قوة:** صفحة محل كاملة + زر «اطلب الآن»

---

### 3️⃣ سوق الأقمشة — «اختر قماشك» (1.5 دقيقة)

**الرابط:** `/marketplace`

**ماذا تقول:**
> «التاجر يبيع الأقمشة B2C وB2B — والخياط يطلب منه مباشرة.»

**ماذا تفعل:**
- تصفّح الأقمشة
- افتح منتج (صوف إيطالي / قطن صيفي)
- أظهر السعر والمخزون

---

### 4️⃣ تسجيل الدخول — «كل الأدوار» (1 دقيقة)

**الرابط:** `/login`

**ماذا تقول:**
> «المنصة تدعم 5 أدوار: عميل، خياط، تاجر، مندوب، مدير — كل واحد له لوحة خاصة.»

**أزرار الدخول السريع:**

| الزر | الجوال | اللوحة |
|------|--------|--------|
| عميل | `966511111111` | `/dashboard/customer` |
| خياط | `966533333333` | `/dashboard/tailor` |
| تاجر | `966544444444` | `/dashboard/merchant` |
| مندوب | `966522222222` | `/dashboard/rep` |
| مدير | `966500000000` | `/dashboard/admin` |

> اضغط **عميل** أولاً للمتابعة.

---

### 5️⃣ لوحة العميل — «رحلة العميل» (2 دقيقة)

**الرابط:** `/dashboard/customer`

**ماذا تفعل:**
1. أظهر الإحصائيات (طلبات نشطة، مقاسات)
2. اضغط **«طلب جديد»** → `/dashboard/customer/orders/new`
3. أو **«حجز قياس منزلي»** → `/dashboard/customer/book-measurement`

**ماذا تقول:**
> «العميل يطلب ثوب أو يحجز مندوب قياس للبيت — 6 خطوات بسيطة.»

**في حجز القياس (إن فتحته):**
- اختيار المنطقة → المندوب → مواصفات الثوب → القماش → الموعد → التأكيد

---

### 6️⃣ تتبع الطلب — «الشفافية» (1.5 دقيقة)

**الرابط:** `/dashboard/customer/orders`

**ماذا تقول:**
> «العميل يتابع طلبه عبر 11 مرحلة — من استلام الطلب حتى التوصيل.»

**ماذا تفعل:**
- افتح أي طلب
- أظهر **OrderTimeline** (مراحل الخياطة المرئية)

**نقطة قوة:** لا يوجد منافس مباشر بهذا التتبع التفصيلي.

---

### 7️⃣ لوحة الخياط — «إدارة المعمل» (1.5 دقيقة)

**الرابط:** `/login` → زر **خياط**

**ماذا تفعل:**
1. `/dashboard/tailor` — إحصائيات اليوم
2. `/dashboard/tailor/orders` — Kanban الطلبات
3. `/dashboard/tailor/staff` — الموظفون

**ماذا تقول:**
> «الخياط يدير معمله كاملاً — طلبات، موظفين، مشتريات، تصنيع.»

---

### 8️⃣ لوحة التاجر — «سوق الأقمشة» (1 دقيقة)

**الرابط:** `/login` → زر **تاجر**

**ماذا تفعل:**
- `/dashboard/merchant` — مبيعات + مخزون
- `/dashboard/merchant/products` — كتالوج المنتجات

---

### 9️⃣ لوحة المندوب — «القياس المنزلي» (1 دقيقة)

**الرابط:** `/login` → زر **مندوب**

**ماذا تفعل:**
- `/dashboard/rep` — مهام القياس النشطة
- أظهر حالات: قيد الانتظار → في الطريق → وصل

**نقطة قوة:** ميزة فريدة — قياس منزلي + GPS.

---

### 🔟 لوحة المدير — «التحكم الكامل» (1 دقيقة)

**الرابط:** `/login` → زر **مدير**

**ماذا تفعل:**
- `/dashboard/admin` — إحصائيات المنصة
- `/dashboard/admin/orders` — كل الطلبات
- `/dashboard/admin/hr` — الموارد البشرية (إن وُجد وقت)

---

## خطة طوارئ

| المشكلة | الحل |
|---------|------|
| الصفحة لا تفتح | جرّب refresh أو نافذة خاصة |
| API بطيء (Render مجاني) | اضغط زر تجريبي → وضع العرض المحلي |
| صفحة فارغة في لوحة | طبيعي إن لم يُسجّل دخول API — جرّب زر تجريبي |
| فيديو Hero لا يعمل | الصور البديلة تظهر تلقائياً |
