## 1. نظرة عامة

**مفصل** منصة سعودية للخياطة الرجالية تجمع:
- **العميل** — طلب ثوب/بدلة، قياس منزلي، تتبع الطلب
- **محل الخياطة** — ERP: طلبات، تصنيع، موظفين، مشتريات، هوية المحل
- **التاجر** — سوق أقمشة: منتجات، مخزون، تسعير B2B، نقطة بيع
- **المندوب** — قياس منزلي + GPS
- **المدير** — تحكم كامل بالمنصة

## 3. دليل العميل (Customer)

### 3.1 الدخول
1. افتح `/login`
2. اضغط **«عميل تجريبي»** أو أدخل `966511111111` / `admin123`
3. تُوجَّه إلى `/dashboard/customer`

### 3.2 لوحة العميل — `/dashboard/customer`
- **طلباتي الأخيرة** — آخر الطلبات وحالتها
- **زر «المتاجر»** — تصفح المحلات
- **زر «قياس منزلي»** — حجز مندوب

### 3.3 طلب جديد — `/dashboard/customer/orders/new`

**الخطوات (5 مراحل):**

| # | المرحلة | ماذا تفعل |
|---|---------|-----------|
| 1 | اختر المحل | ابحث واختر خياطاً |
| 2 | اختر الخدمة | ثوب سعودي / بدلة / تعديل |
| 3 | المقاسات | أدخل القياسات أو اختر «قياس منزلي» |
| 4 | القماش | من المحل أو من السوق |
| 5 | الدفع والتأكيد | عنوان + طريقة دفع |

**اختصار:** من `/shops/[id]` → «اطلب الآن» يفتح الطلب مع المحل محدداً.

### 3.4 حجز قياس منزلي — `/dashboard/customer/book-measurement`

| # | المرحلة | الوظيفة |
|---|---------|---------|
| 1 | المنطقة | أدخل العنوان |
| 2 | المندوب | اختر مندوباً متاحاً |
| 3 | مواصفات الثوب | ياقة، كبك، قصة، موسم |
| 4 | القماش | من المحل أو السوق |
| 5 | الموعد | تاريخ + وقت |
| 6 | التأكيد | إرسال الحجز |

### 3.5 طلباتي — `/dashboard/customer/orders`
- عرض كل الطلبات + الحالة
- اضغط طلباً → `/dashboard/customer/orders/[id]` للتفاصيل والتتبع

### 3.6 مقاساتي — `/dashboard/customer/measurements`
- حفظ مقاساتك لإعادة استخدامها في طلبات لاحقة

### 3.7 العناوين — `/dashboard/customer/addresses`
- إدارة عناوين التوصيل

### 3.8 الملف الشخصي — `/dashboard/customer/profile`
- تعديل الاسم والبيانات

## 4. دليل التاجر (Merchant) — سوق الأقمشة

### 4.1 الدخول
- `/login` → **«تاجر تجريبي»** أو `966544444444` / `admin123`

### 4.2 لوحة التاجر — `/dashboard/merchant`
- إحصائيات المبيعات والمخزون
- روابط سريعة للمنتجات والطلبات

### 4.3 المنتجات — `/dashboard/merchant/products`
| الإجراء | كيف |
|---------|-----|
| عرض الكتالوج | قائمة المنتجات مع السعر والمخزون |
| إضافة منتج | `/dashboard/merchant/products/add` |

### 4.4 التسعير المتدرج (B2B) — `/dashboard/merchant/pricing`
- شرائح خصم حسب الكمية (10+ / 50+ / 20+)
- **إضافة شريحة:** زر «إضافة شريحة» → منتج + كمية + نسبة خصم
- **حذف/تفعيل:** أزرار في كل شريحة

### 4.5 المخزون — `/dashboard/merchant/inventory`
- مستويات المخزون وتنبيهات النقص

### 4.6 طلبات التوريد B2B — `/dashboard/merchant/b2b`
- طلبات الجملة من محلات الخياطة

### 4.7 المحاسبة — `/dashboard/merchant/accounting`
- شجرة حسابات، قيود، ميزان مراجعة

### 4.8 المالية — `/dashboard/merchant/finances`
- تقارير الإيرادات والمصروفات

## 5. دليل محل الخياطة (Tailor Shop)

### 5.1 الدخول
- `/login` → **«خياط تجريبي»** أو `966533333333` / `admin123`

### 5.2 لوحة الخياط — `/dashboard/tailor`
| البطاقة | المعنى |
|---------|--------|
| طلبات اليوم | طلبات جديدة اليوم |
| قيد الانتظار | طلبات تحتاج إجراء |
| إيراد اليوم | مجموع المبيعات |

**أزرار:**
- **طلب جديد** → `/dashboard/tailor/orders/new`
- **الموظفون** → `/dashboard/tailor/staff`

### 5.3 إدارة الطلبات — `/dashboard/tailor/orders`
| الإجراء | الوظيفة |
|---------|---------|
| عرض الطلبات | فلترة: جديد / مؤكد / قيد التنفيذ / جاهز |
| تفاصيل الطلب | `/dashboard/tailor/orders/[id]` |
| تغيير الحالة | قبول / رفض / نقل لمرحلة التصنيع |

**مراحل الطلب (Kanban):**
```
PENDING → CONFIRMED → CUTTING_FABRIC → SEWING_ASSEMBLY → IRONING_FINISHING → PACKING_WRAPPING → DELIVERED
```

### 5.4 التصنيع — `/dashboard/tailor/manufacturing`
- عرض مهام التصنيع حسب المرحلة
- **بدء مهمة** / **إكمال مهمة** — تحديث الحالة
- فلتر حسب: قص / خياطة / كي / تغليف

### 5.5 الموظفون — `/dashboard/tailor/staff`
| الإجراء | كيف |
|---------|-----|
| عرض الموظفين | قائمة بالاسم والمنصب والراتب |
| إضافة موظف | زر «+» → اسم + منصب + راتب |
| حذف | زر الحذف |

### 5.6 المشتريات — `/dashboard/tailor/procurement`
- أوامر شراء الأقمشة من الموردين
- حالات: مسودة / قيد الانتظار / مؤكد / مستلم

### 5.7 المالية — `/dashboard/finances`
- تقارير مالية لمحل الخياطة

### 5.8 إعدادات المحل + الهوية — `/dashboard/tailor/settings`

| القسم | الوظيفة |
|-------|---------|
| الملف الشخصي | اسم المحل، هاتف، عنوان |
| **هوية المحل (White-Label)** | ألوان + شعار + معاينة |
| التوصيل | تفعيل/تعطيل شركات التوصيل |
| ساعات العمل | جدول أسبوعي |

**الهوية تظهر للعملاء في:** `/shops/[id]` — ألوان مخصصة للمحل.
